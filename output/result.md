# 061 — bop ui: global search (implement)\n\n## Summary\nImplemented a dedicated global search overlay in `bop ui`:\n- Press `/` in kanban to open a centered **Global Search** overlay\n- Typing filters cards by **ID substring** across all states (`pending`, `running`, `done`, `failed`, `merged`)\n- Results render as a flat list with state badges (`[running] card-id`)\n- `Enter` jumps focus to the selected card and returns to kanban\n- `Esc` cancels search and restores the previously selected card/view\n\n## Implementation details\n- Added `Mode::Search` and `SearchState` to UI app state:\n  - centered overlay with search input + selectable result list\n- Updated key handling in `ui/input.rs`:\n  - `/` opens global search\n  - Search mode handles typing, backspace, up/down, enter, esc\n  -
